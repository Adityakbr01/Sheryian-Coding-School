# SheryMemory Extension - Source Code

## Overview
This extension is built using TypeScript and bundled using esbuild.

## Build Instructions

1. Install dependencies:
   npm install

2. Build the extension:
   npm run build

3. Generate production zip:
   npm run prod

## Build Tools Used

- Node.js (v18 or higher)
- npm (v9 or higher)
- esbuild

## Project Structure

- src/ → source code (TypeScript)
- dist/ → production build (generated)

## Notes

- No minified or obfuscated code is included in the source.
- All logic is written in TypeScript and compiled using esbuild.
- The dist folder is generated during build and is not included in source submission.
